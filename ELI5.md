# Rackcheck, explained simply

A DAW project is like a recipe for a music session. It remembers tracks and settings, but it may depend on plugins that are installed only on one computer.

Rackcheck is intended to read a supported project file and make a list of the plugins it finds, where they are used, and which ones appear to be installed or missing. That helps when opening an old session or sending a project to someone else. It is an inventory and checking tool, not a tool that converts or edits your music project.

The repository describes the software as an early Phase 0 skeleton, so planned features and format support are not all complete yet. Its future product pricing/licensing plan is a separate question from the license for the source code. Knowledge-base data may also have its own license.
